# DoostetDaram + ControlMe

دو پروژه اندرویدی پایه:
- دوستت دارم: رابط کودک، انیمیشن ۳۵ ثانیه‌ای و درخواست رسمی MediaProjection
- کنترل می: رابط والد و قاب عمودی

این نسخه هنوز VPS، pairing و انتقال واقعی تصویر زنده را پیاده‌سازی نمی‌کند.
مجوزهای امنیتی Android دور زده نمی‌شوند.
برای ساخت APK به Android SDK و Gradle نیاز است.
